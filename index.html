Nota metodológica: os KPIs financeiros consideram apenas vendas com status “Pago”. O lucro é estimado como (quantidade × valor unitário − desconto) − (quantidade × custo unitário). O desconto ausente foi tratado como zero; o cliente ausente foi identificado como “Não informado”. Um ID duplicado foi mantido apenas na primeira ocorrência, conforme o tratamento definido no projeto. Valores de desconto foram lidos preservando o ponto decimal do CSV (ex.: 100.0 = R$ 100,00).
